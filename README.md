# Chat'Donald's

Juego interactivo de restaurante pixel art con participación del chat de Twitch.

## Proyecto

Chat'Donald's es un proyecto independiente de BotEB14-FoodTV.

El objetivo es construir un restaurante virtual interactivo con:

- Mapa pixel art.
- Personajes y sprites.
- Mesas y estaciones de trabajo.
- Movimiento y colisiones.
- Editor visual de mapeo.
- Estado de juego centralizado.
- Sincronización en tiempo real.
- Integración con Twitch.
- Comandos del chat.
- Despliegue mediante Render.
- Monitorización mediante UptimeRobot.

## Regla de desarrollo

Una funcionalidad solamente se considera terminada después de ser probada.

Se distinguirá entre:

- Código escrito.
- Código probado.
- Código desplegado.

## Seguridad

Las credenciales y secretos nunca deben almacenarse en el código público del repositorio.

Las variables sensibles se configurarán mediante variables de entorno en Render.
